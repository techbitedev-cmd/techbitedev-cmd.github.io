Privacy Policy

Last updated 12 September 2026

TechBite is run by one person. This website has no accounts, no sign-up, no comment system, no analytics and no advertising. It sets no cookies. If you only read this site, no personal data about you is collected at all.

01 Who this covers

“TechBite” is a personal media project that publishes short educational videos on YouTube and TikTok, operated by Irakli Migriauli. It includes this website and TechBite Publisher — the private, self-hosted tool the operator uses to upload TechBite videos to TechBite’s own channels.

TechBite Publisher is not offered to other people. It has no users other than the operator, and it cannot post to any account other than the TechBite accounts the operator owns.

02 What the website collects

Nothing. The site is a set of static pages. It has no forms, no tracking pixels, no analytics scripts and no cookies of its own.

Web fonts are loaded from Google Fonts. As with any external resource, your browser’s request reaches Google and exposes your IP address and user agent to it. That request is governed by Google’s own privacy policy.

The site is served by a static hosting provider, which keeps standard server access logs (IP address, timestamp, requested path) for security and reliability. TechBite does not use those logs for profiling and does not combine them with anything else.

03 What TechBite Publisher accesses

The tool runs on the operator’s own computer. When the operator connects it to a platform, it receives and stores the following, locally:

  • OAuth access and refresh tokens for the TechBite YouTube channel and the TechBite TikTok account.
  • Basic account information returned by the platform when a post is prepared — for TikTok, the creator nickname, avatar and the privacy settings the account permits — used to fill in the posting form correctly.
  • The video files and their metadata — title, description, tags, caption, thumbnail, scheduled publish time.

These tokens grant access only to the operator’s own accounts. No third party’s account is ever connected, and the tool never requests or receives data about anyone who watches, likes or comments on a TechBite video.

04 How that information is used

Only to upload TechBite videos to TechBite channels and to set their titles, descriptions, tags, thumbnails and publish times. It is not used for advertising, profiling, scoring or training, and it is never sold, rented or shared for marketing.

05 Where it is stored, and for how long

Tokens and video metadata are stored on the operator’s own computer and in the operator’s own private Google Drive and Google Sheets account, which only the operator can access. Nothing is stored on this website, and there is no shared or public database.

Tokens are kept only while the integration is in use. When access is revoked or the integration is retired, the stored tokens are deleted. Video files and their metadata are kept as long as the videos remain published.

06 Third-party services

TechBite Publisher sends data to the following services, and to no others:

  • TikTok — the Content Posting API and Login Kit, to upload videos to the TechBite TikTok account.
  • YouTube / Google — the YouTube Data API, to upload videos and thumbnails to the TechBite channel; Google Drive and Google Sheets, as the operator’s private storage for video files and the publishing queue.
  • OpenAI — the topic text and the generated script are sent to generate the narration script, voice-over and caption timings. No personal data of any viewer is included.

Each of these services handles the data it receives under its own privacy policy.

07 Revoking access

The operator can disconnect TechBite Publisher at any time from the TikTok app settings or the Google account permissions page. Doing so immediately invalidates the stored tokens.

08 Children

TechBite is not directed at children under 13, does not knowingly collect any data from them, and its videos are not marked as made for kids.

09 Your rights

Because no personal data about visitors is collected, there is usually nothing to access, correct or delete. If you believe TechBite holds information about you — for example if you appear in a video — write to techbite.dev@gmail.com and it will be removed or corrected.

10 Changes

If this policy changes, the “last updated” date above changes with it. Material changes will be summarised at the top of this page.
